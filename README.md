# My3D_Design

## Opening the `.f3d` File
The `.f3d` file is a **Fusion 360 project file**.  

To open it:
1. Download the `.f3d` file from this repository.  
2. Open **Autodesk Fusion 360**.  
3. Go to **File → Open → Open from my computer**, and select the `.f3d` file.  
4. You can now view, edit, or export the 3D model as needed.

## Viewing the Design Draft
A **PDF draft** of the 3D design is also included for easy viewing.  

- Open the `.pdf` file in any standard PDF viewer.  
- It contains the **technical drawings and dimensions** of the design.
